# 2026-09-20

## 今日やったこと

- Physics-Constrained Scientific Computing構想を確認した。
- 最初の対象を、自分のインフレーション研究で使う単一場背景計算に定めた。
- MVPの設計を一問ずつすり合わせた。
  - stable Rustを使う。
  - 自然単位系 `c = hbar = 1` とPlanck単位 `M_pl = 1` を使うが、物理次元は型に残す。
  - コア型を `Quantity<Dimension, Value>` とする。
  - 型レベルの次元演算には `typenum` を使う。
  - 質量次元は半整数まで扱う。
  - 数値型は最初は `f64` とし、将来の `ndarray` や自動微分に備えて `Value` はジェネリックにする。
  - 状態を `phi`, `dphi`, `a` とし、`H` はFriedmann方程式から各ステップで計算する。
  - ポテンシャルは `Potential` traitで表し、最初は二次ポテンシャルを使う。
  - 固定刻みRK4を小さく実装する。
  - `State`、`StateDerivative`、`StateDelta`を別の型として扱う。
  - 60 e-fold到達または `epsilon_H >= 1` で計算を終了する。
  - 結果をCSVへ出力し、gnuplotなど外部ツールで描画する。
- 合意内容を `docs/mvp-design.md` に保存した。
- 一度に一問ずつ認識を合わせる個人用skill `incremental-alignment` を作成し、自動発動を有効にした。
- Homebrew経由で `rustup` を導入し、stable Rust 1.98.1を設定した。
- `.zshrc` にrustupのPATHを追加した。
- リポジトリをRust 2024 editionのライブラリcrateとして初期化した。
- `cargo test` を実行し、初期状態のテストが通ることを確認した。
- `typenum`を依存関係に追加した。
- コア型 `Quantity<Dimension, Value>` を実装した。
- 半整数刻みの質量次元と、主要な意味別type aliasを追加した。
- 同一次元の加算・減算、値の明示的な生成・取得を実装した。
- 4件の単体テスト、フォーマット検査、Clippyの警告検査がすべて通った。
- 次元付き物理量どうしの乗算を実装し、質量指数が型レベルで加算されるようにした。
- `M^(1/2) * M^(1/2) = M^1`を含む6件の単体テストが通った。
- 次元付き物理量どうしの除算を実装し、質量指数が型レベルで減算されるようにした。
- 同一次元の除算が無次元量になることを含む8件の単体テストが通った。

### 追記（Claude Codeとの作業）

- リポジトリを `git init` し、`target/` を `.gitignore` に入れて履歴管理を始めた。
- クレートを `dimension` / `quantity` / `state` / `potential` / `integrate` / `scalar_field` / `background` モジュールに分割した。
- 型レベルの `DimMul` / `DimDiv` / `DimSqrt` を実装し、乗算・除算・平方根を復元した。
- `typenum::PartialDiv` が符号付き整数でも動くことを確認し、平方根を半整数グリッド上に限定した。
- 生の数値による係数倍（左右両方向）と符号反転を実装した。
- `State` / `StateDerivative` / `StateDelta` を別の型として実装し、`Time * StateDerivative -> StateDelta`、`State + StateDelta -> State` だけを経路として残した。
- `Potential` traitと二次ポテンシャルを実装し、勾配を有限差分と突き合わせた。
- ポテンシャルやFriedmann方程式を知らない汎用RK4層（`System` trait、`rk4_step`）を実装した。
- `ScalarFieldSystem` にFriedmann拘束からの `H`、`epsilon_H`、slow-roll初期速度を実装した。
- de Sitter極限で解析解 `a = exp(H t)` と相対誤差 1e-10 未満で一致することを確認した。
- 終了判定（N = 60 到達、または `epsilon_H >= 1`）と CSV 出力を実装した。
- `examples/quadratic_inflation.rs` を追加した。`phi_0 = 16 M_pl`、`m = 10^-6 M_pl` で145,060ステップ、N = 60.0000、`phi = 4.2114 M_pl` に到達した。
  - slow-rollの予測 `phi_f = sqrt(phi_i^2 - 4N) = 4` とよく一致した。
